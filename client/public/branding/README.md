# Kubear Branding & Logo Assets Folder

You can directly paste or replace your logo SVG/PNG files here. The entire website will automatically update everywhere!

## Files in this folder:

1. **`logo.svg`** (Primary Logo)
   - Used in the navigation header, mobile bar, and light backgrounds.
   - Simply paste your SVG code or replace this file.

2. **`logo-dark.svg`** (Inverse / Dark Background Logo - Optional)
   - Used on dark footer or inverted banners.
   - If not provided, it will automatically use `logo.svg`.

3. **`favicon.svg`** (Browser Tab Icon)
   - Used for browser tabs and mobile bookmark icons.

---

### How to use:
- **Direct SVG**: Open `/client/public/branding/logo.svg` and paste your SVG code directly.
- **Image File**: You can also place a `/client/public/branding/logo.png` here.
